# 审核流程

## 触发条件

一批图（5张）生成完毕后，派 dsh 审核。

## 执行步骤

1. 状态更新为「审核中」
2. 准备审核材料：
   - 生成的图片（待审核/目录下）
   - 产品实拍图（作为对比参照）
   - 审核清单（见 rules/review-checklist.md）
   - 平台规则 + 产品注意事项
   - 产品类别（决定C-03/C-04的严格程度）
3. 发给 dsh，附上完整审核指令
4. dsh 返回逐张结果

## 处理审核结果

```
全部通过
  → 图片移入 生成图/待验收/
  → 状态更新为「待验收」

有不合格
  → 看返工次数
    ├── < 2次 → 读 workflows/rework.md → 进入返工
    └── ≥ 2次 → 状态「人工处理」
                → 写人工处理报告到 汇报/人工处理/{任务ID}.md
```

## 调用 dsh 的方式

通过 DeepSeek API（config.json 里的 deepseek.api_key）调用 DeepSeek Harness。

dsh 可以读取本地图片文件，所以直接把图片路径发给它。

## 注意

- dsh 只负责审核，不负责生图
- 审核结果写入任务队列的「dsh反馈」列
- dsh审核可以和下一批生图并行（不用等审核完再开始下一批）

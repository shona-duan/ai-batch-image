# 返工流程

## 触发条件

dsh 审核后有不合格的图，且返工次数 < 2。

## 返工策略

| 返工次数 | 策略 |
|---------|------|
| 第1次 | **微调prompt**：根据dsh反馈修改具体措辞，比如"文字居中留边距"、"产品放大到60%画面" |
| 第2次 | **换策略**：换风格组合或换排版方向，不在原方向上继续微调。比如从"左文右图"换成"产品居中"，从"爆款感"换成"简约" |
| 超过2次 | **标记人工处理**，交给用户决定 |

## 执行步骤

```
1. 读取 dsh 反馈（具体问题描述）
2. 分析原因
3. 只重新生成不合格的那几张（不是整批重做）
4. 返工次数 +1，写入任务队列
5. 重新派 dsh 审核
```

## 人工处理

返工超过2次：

1. 状态设为「人工处理」
2. 写报告到 `%WORKSPACE%\汇报\人工处理\{任务ID}.md`，格式：

```markdown
# 人工处理：{任务ID}

- 商品ID：xxx
- 图片类型：xxx
- 平台：xxx

## 问题
第X张主图具体什么问题

## 已尝试
1. 第1次：做了什么修改 → 结果
2. 第2次：做了什么修改 → 结果

## 建议
Codex的建议（比如去掉文字、换构图方式等）

## 相关图片
%WORKSPACE%\素材库\{商品ID}\生成图\待审核\具体文件名
```

# 豆包集成（火山引擎API）

## 1. OCR 外包装文字

**触发条件**：产品库「外包装文字」列为空，但素材库有外包装照片。

```
调用方式：火山引擎 API → 豆包视觉模型
API Key：config.json → api_keys.volcengine.api_key
Endpoint：config.json → api_keys.volcengine.endpoint_id

输入：外包装照片（%WORKSPACE%\素材库\{商品ID}\外包装\ 下的图片）
输出：包装上的所有文字（逐字识别）
后处理：写回产品库「外包装文字」列，直接使用
```

外包装字体规整，OCR准确率高，不需要用户确认。直接写入直接用。

**如果没有外包装照片：**
- 医疗器械 → 任务阻塞，状态设为「人工处理」，备注"缺外包装文字（必需）"
- 其他类别 → 可继续，卖点从任务要求和产品名称推导

## 2. 写中文文案

**触发条件**：图上需要出现中文营销文案（标题、卖点文字等）。

```
调用方式：火山引擎 API → 豆包文本模型

输入：
  - 产品名称
  - 外包装文字
  - 目标人群/方向
  - 平台（拼多多/抖音）
  - 产品类别

要求：
  - 医疗器械类：文案必须在外包装文字范围内
  - 其他类别：文案与产品信息一致
  - 抖音+医疗器械：避开敏感词（见 rules/sensitive-words.md）
  - 简短有力，适合图片展示（每条不超过8个字）

输出：2-3条备选文案
后处理：选最合适的嵌入生图prompt
```

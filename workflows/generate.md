# Phase 2：分批生图

## 批次拆法

拿到 content_plan.json 后，每 5 张一批，每批用**独立对话**：

| 平台 | 批次拆法 | 生成顺序 |
|------|---------|---------|
| 拼多多 | A1-5, A6-10, B1-5, B6-10（共4批） | A两批先做 → B两批后做 |
| 抖音 | A1-5, B1-5（共2批） | 可并行 |

投流素材：不走 content_plan，直接5张一批生图。

## 每批对话的输入

```
1. content_plan.json 中该批次的5条指令（投流素材则是任务要求+产品信息）
2. prompt模板（从规则库按平台+图片类型选）
3. 被选中的同行参考图（content_plan里ref_image指定的那几张）
4. 爆款参考图 + 产品实拍图
5. 产品注意事项
```

## Prompt 组装

```
prompt = 模板（从规则库按平台+类型选）
       + 产品名称（从产品库）
       + 卖点（从content_plan的selling_point）
       + 文案（从content_plan的copy_text）
       + 风格组合（从content_plan的style_tags）
       + 同行参考图（借鉴布局，卖点已换成自己的）
       + 产品参考图（爆款参考+产品实拍）
       + 特殊要求（从任务队列）
       + 注意事项（从产品库）
```

## 投流素材的prompt重点

投流素材目标是**点击率高、转化高、卖点吸引客户**：
- 强视觉冲击，第一眼抓住注意力
- 卖点精准，一张图只打一个点
- 风格可以比主图更大胆（对比更强、文字更大）

## 尺寸要求

| 图片类型 | 尺寸 | 文件大小 |
|---------|------|---------|
| 主图/套图/投流素材 | 800×800 | ≤1M |
| 详情页 | 3:4比例 | ≤1M |

## 输出

每张生成的图：
- 文件名：`{任务ID}_{Set}_{序号}.png`，如 `鼻喷护理-1012-01_A_03.png`
- 存入：`%WORKSPACE%\素材库\{商品ID}\生成图\待审核\`
- 记录每张图对应的prompt和seed

## 并行控制

- 同时最多处理 2 个链接
- 同一链接内：拼多多 A→B 串行，抖音 A+B 可并行
- dsh审核可以和下一批/下一个链接的生图并行

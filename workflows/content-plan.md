# Phase 1：内容规划

完整链接任务（非投流素材）在生图前先做内容规划。

## 触发条件

图片类型为"主图+详情页"或"双尺寸主图"时执行。投流素材跳过本步骤。

## 执行方式

每个链接开一次**独立对话**，只做文案规划，不生图。

## 输入

1. 产品库中该商品的所有信息（名称、外包装文字、注意事项、产品类别）
2. 同行参考图（素材库/{商品ID}/同行参考/ 下的所有图片）
3. 爆款参考图（素材库/{商品ID}/爆款参考/）
4. 任务要求（卖点方向、特殊要求）
5. 风格标签池（从规则库读取）
6. 平台规则（医疗器械+抖音时还要过敏感词替换）

## 参考图处理

用户放多少张参考图都行（通常8-20张），不限数量，文件名也不限。
全部看一遍，筛选出最有参考价值的记入 content_plan。
生图时每批只带被选中的参考图。

## 输出

content_plan.json，存到 `%WORKSPACE%\素材库\{商品ID}\生成图\content_plan.json`

## 规划要点

- 同行参考图：分析布局、排版、视觉风格、卖点角度，布局可借鉴，卖点文字换成自己的
- 主图卖点不重复，覆盖外包装文字的主要卖点
- 风格标签要有变化，避免全部图长一个样
- 拼多多详情页每张对应一张主图，展开它的卖点做详细介绍
- 抖音两套图面向不同人群，卖点方向和风格可以完全不同
- 如果任务指定了人群方向 → 按指定的来；没指定 → 自行区分

## 医疗器械特殊要求

产品类别=医疗器械时：
- selling_point **必须**从外包装文字逐字选取，不能编造或改写
- 抖音平台的 copy_text 要过敏感词替换（见 rules/sensitive-words.md）

# 平台规则

## 通用差异（所有产品类别）

| | 拼多多 | 抖音 |
|---|---|---|
| 模板 | TPL-01/02/03 | TPL-11/12/13 |
| 整体风格 | 爆款感为主，强转化 | 内容感为主，种草调性 |
| 链接结构 | 10张1:1主图 + 10张3:4详情页 | 5张1:1主图 + 5张3:4主图 |
| 生图顺序 | A→B 串行（详情页基于主图） | A+B 可并行（面向不同人群） |

## 医疗器械类额外差异（产品类别=医疗器械时）

| | 拼多多 | 抖音 |
|---|---|---|
| 医疗器械用语 | 可以用，但不超出外包装范围 | **严禁**，必须替换为日常用语 |
| 敏感词检查 | 不需要 | **必须**查 sensitive-words.md 逐一替换 |

## 通用合规红线（所有平台）

- R-01：不出现价格信息
- R-02：不改变产品真实规格、包装形式和数量
- R-03：产品形象必须用自己的，不能混入同行产品
- R-04：同行参考图只借布局和设计思路，卖点文字换成自己的
- R-05：卖点优先从外包装文字选取，保持一致性
- R-06：医疗器械类卖点**必须只**从外包装文字选（已过广审，超出会被投诉）

## 产品类别判断

读产品库的「产品类别」字段：
- **医疗器械** → 走严格合规路线（外包装卖点强制、抖音敏感词替换）
- **餐具 / 日用百货 / 美妆个护 / 食品 / 其他** → 走通用规则

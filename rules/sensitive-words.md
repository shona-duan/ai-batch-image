# 抖音敏感词替换表

**仅医疗器械类产品上抖音时使用。** 其他产品类别不需要查此表。

在写 prompt 和文案时，逐一检查以下词汇，发现就替换：

| 敏感词（禁用） | 替换为 |
|---------------|--------|
| 医疗器械 | 专业护理产品 |
| 医用 | 专用 / 专业 |
| 治疗 | 改善 / 呵护 / 缓解 |
| 药物 | 护理产品 |
| 疗效 | 效果 / 体验 |
| 处方 | 专业推荐 |
| 临床 | 专业验证 |
| 病 / 疾病 | 问题 / 困扰 |
| 患者 | 使用者 / 用户 |
| 手术 | 护理方案 |
| 消毒 | 清洁 / 洁净 |
| 灭菌 | 洁净处理 |
| 无菌 | 洁净 |
| 抗菌 | 呵护 / 守护 |
| HPV | （视上下文）私密护理 / 女性守护 |

**原则**：把医疗语境转换为日常护理语境，保持含义但去掉医疗色彩。

**检查时机**：
1. Phase 1 内容规划时：规划文案就要用替换后的词
2. 豆包写文案时：prompt里注明"抖音平台，禁用医疗术语"
3. dsh 审核时：C-04 检查项
